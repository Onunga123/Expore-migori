# Explore Migori County

Explore Migori County is a static tourism website designed to showcase the natural beauty, cultural heritage, historical sites, and travel opportunities available in Migori County, Kenya.

The website helps visitors discover popular destinations, learn about local attractions, explore available services, make travel-related bookings, and contact the tourism team.

## Features

- Attractive landing page introducing Migori County
- Information about Migori County and its cultural heritage
- Popular destination listings
- Travel deals and destination recommendations
- Guided tours and customized travel itineraries
- Cultural experience information
- Flight and hotel booking forms
- Contact form and contact information
- Responsive page layout for different screen sizes
- Image-based presentation of tourist attractions

## Destinations Featured

The website provides information about several attractions in and around Migori County, including:

- **Gogo Falls**
- **Mugabo Caves**
- **Chinato Crying Stone**
- **Thimlich Ohinga**
- **Sori and Senye Beaches**
- **Aluru and Migingo Islands**

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Onunga123/Expore-migori.git
   ```

2. Open the project folder:

   ```bash
   cd Expore-migori
   ```

3. Open `index.html` in a web browser.

No server or additional dependencies are required because this is a static HTML and CSS website.

## Navigation
